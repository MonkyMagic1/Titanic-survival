# Titanic Survival Prediction

Учебный проект по прогнозированию выживания пассажиров «Титаника».
Подготовлен и защищён в рамках курсовой работы.

Модель классифицирует пассажиров по данным о возрасте, поле,
классе билета, стоимости проезда и других признаках.

## Технологии

Python 3.13, pandas, scikit-learn, matplotlib.

Алгоритм — k-ближайших соседей (KNN), `n_neighbors=3`.

## Обработка данных

- Удаление идентификатора пассажира, номера билета и номера каюты.
- Сохранение имён отдельно от признаков модели.
- Заполнение пропусков возраста фиксированными значениями
  в зависимости от класса билета.
- Заполнение пропусков порта посадки.
- Преобразование пола и порта посадки в числовые признаки.
- Создание признака путешествия без родственников.
- Стандартизация признаков: обучение StandardScaler
  на тренировочной выборке и применение к тестовой.

## Оценка модели

Датасет содержит 891 запись.

- Обучающая выборка — 712 пассажиров.
- Тестовая выборка — 179 пассажиров.
- Разбиение — 80/20, `random_state=42`, `stratify=y`.
- Accuracy на тестовой выборке — **79,33%**.

Матрица ошибок:

| Фактический исход | Прогноз: не выжил | Прогноз: выжил |
| --- | ---: | ---: |
| Не выжил | 94 | 16 |
| Выжил | 21 | 48 |

Результат получен на одном фиксированном разбиении данных.
Кросс-валидация не выполнялась.

## Установка и запуск

Команды для macOS / Linux. Требуется Python 3.13.

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

Запускайте программу из папки проекта, где находится `titanic.csv`.

Программа выводит прогнозы для тестовых пассажиров, точность,
элементы матрицы ошибок и две круговые диаграммы.
Чтобы перейти ко второй диаграмме, закройте окно первой.

## Файлы

- `main.py` — обработка данных, обучение, оценка и визуализация.
- `titanic.csv` — исходный учебный датасет.
